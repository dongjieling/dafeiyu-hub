# 安装中转站

> 从零开始，约 20 分钟。

---

## 一、前置条件

| 项目 | 要求 | 检查方式 |
|---|---|---|
| 系统 | Windows 10/11 x64 | — |
| Python | 3.10 以上 | `python --version` |
| AstrBot | 已安装并能正常聊天 | 打开面板 `http://127.0.0.1:6185` |
| LivingMemory | 插件已安装且在工作 | 面板 → 插件 → 能看到它 |
| DeepSeek Key | 能调用 `deepseek-chat` | 在 AstrBot 里已配好 |
| 磁盘 | 500 MB 空闲 | — |

> Python 推荐直接用 AstrBot 内置的：
> `C:\Users\<用户名>\AppData\Local\AstrBot\backend\python\python.exe`
> 这样不用另装环境。

---

## 二、第一步：开启记忆库的外部接口

中转站靠 HTTP 访问 LivingMemory，所以先把它打开。

### 2.1 开启

AstrBot 面板 → 插件 → **LivingMemory** → 配置：

```
外部记忆 API
  ├─ enabled: true          ← 开启
  ├─ listen_host: 127.0.0.1
  └─ listen_port: 7801
```

保存后**重载插件**（或重启 AstrBot）。

### 2.2 生成密钥

在 QQ 里对机器人发（用主人号私聊）：

```
/lmem apikey create hub write
```

它会回复一串 `lm_...` 开头的令牌。**这串只显示一次，复制保存。**

### 2.3 验证

```powershell
curl http://127.0.0.1:7801/page/external/health `
  -H "Authorization: Bearer lm_你的令牌"
```

正常返回：

```json
{"status":"ok","plugin_version":"2.14.2","ready":true}
```

如果返回 404，说明 `enabled` 没生效，回去重载插件。

---

## 三、第二步：运行中转站

### 3.1 下载

从 Releases 下载：

```
大肥鱼中转站-0.1.0-portable.exe    （约 105 MB）
```

### 3.2 放置

**放在普通目录**，例如：

```
D:\大肥鱼中转站\
```

⚠️ 不要放在：
- `C:\Program Files`（需要管理员权限写数据）
- 被安全策略限制的目录
- 带中文或空格的深层路径（可能出问题）

### 3.3 首次运行

双击 EXE。会看到：

```
┌──────────────────────────────────┐
│ 大肥鱼中转站          ● 服务未启动 │
│ 状态  [启动服务] [停止服务]        │
└──────────────────────────────────┘
```

### 3.4 配置

点左侧「配置」：

| 字段 | 填什么 |
|---|---|
| 服务端口 | `8787`（保留默认） |
| Python 路径 | `C:\Users\<用户名>\AppData\Local\AstrBot\backend\python\python.exe` |
| 自动启动服务 | 勾上 |

保存。

### 3.5 填记忆库密钥

打开 sidecar 配置（同目录下 `sidecar\config.json`），填三项：

```json
{
  "persona_db": "C:\\Users\\<用户名>\\.astrbot\\data\\data_v4.db",
  "astrbot_config": "C:\\Users\\<用户名>\\.astrbot\\data\\cmd_config.json",
  "lm_key": "lm_你刚才复制的令牌",
  "write_scope": "一号:FriendMessage:<主人QQ号>"
}
```

`write_scope` 的格式：`<AstrBot平台名>:FriendMessage:<主人QQ号>`，

平台名一般是 `一号`（在 AstrBot 平台配置里能看到）。

### 3.6 启动

点「启动服务」。三个灯应该依次变绿：

```
● 本地服务      127.0.0.1:8787
● 记忆库        LivingMemory 已连接
● 上游模型      DeepSeek Key 已加载
```

### 3.7 验证

```powershell
curl http://127.0.0.1:8787/health
```

```json
{
  "status": "ok",
  "persona_id": "dafeiyu",
  "persona_chars": 1853,
  "lm_connected": true,
  "upstream_key_loaded": true
}
```

`persona_chars` 必须大于 0，否则人格没读到。

---

## 四、第三步：接入客户端

### 4.1 桌面宠物（AIRI）

设置 → 服务来源 → 聊天 → OpenAI 兼容：

```
Base URL: http://127.0.0.1:8787/v1
API Key:  local
模型:     deepseek-chat
```

### 4.2 测试

问桌宠：「你叫什么名字」

- 答「大肥鱼」→ 人格注入成功
- 答「我是 AI 助手」→ 人格没读到，回去查 `persona_db` 路径

---

## 五、第四步：验证记忆

### 5.1 写一条

在桌宠那里说：

```
我明天要去医院复查胃
```

等 10 秒。

### 5.2 查日志

```
%APPDATA%\dafeiyu-hub\hub.log
```

应出现：

```
写回记忆: 他明天要去医院复查胃… (重要性 0.8)
```

### 5.3 验证 QQ 能读到

在 QQ 里问机器人：

```
我明天要干嘛
```

她应能答出「复查胃」。

---

## 六、开机自启（可选）

方案 A：任务计划程序

1. Win+R → `taskschd.msc`
2. 创建任务 → 触发器「登录时」
3. 操作 → 启动程序 → 选 `大肥鱼中转站.exe`
4. 勾选「不管用户是否登录都要运行」不要选（需要桌面）

方案 B：启动文件夹

1. Win+R → `shell:startup`
2. 把快捷方式复制进去

---

## 七、卸载

1. 托盘右键退出
2. 删除程序目录
3. 删除 `%APPDATA%\dafeiyu-hub`（会丢归档与日志）
4. AstrBot 里把外部 API 关掉、`/lmem apikey revoke hub`

---

## 八、安装检查清单

| # | 检查 | 通过标准 |
|---|---|---|
| 1 | Python 存在 | 配置页填的路径能打开 |
| 2 | LivingMemory 外部 API | 7801 端口有响应 |
| 3 | lm_key 正确 | 记忆库灯绿 |
| 4 | AstrBot 数据库路径 | 人格灯显示字数 > 0 |
| 5 | DeepSeek Key | 上游灯绿 |
| 6 | write_scope 正确 | QQ 能召回桌宠写的记忆 |
| 7 | 客户端地址 | AIRI 能正常聊天 |
