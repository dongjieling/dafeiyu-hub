# 安装桌面宠物（AIRI）

> 目标：桌面上出现一个会动的角色，能聊天、能记住你。

---

## 一、为什么选 AIRI

| 对比 | AIRI | 序列帧桌宠 | Live2DViewerEX |
|---|---|---|---|
| 能换 Live2D 模型 | ✅ | ❌ | ✅ |
| 能接自建 API | ✅ | ✅ | ❌ |

| 开源 | ✅ MIT | 视项目 | ❌ |
| 免费 | ✅ | ✅ | 付费 |

## 二、安装

### 2.1 下载

```
https://github.com/moeru-ai/airi/releases
```

选 `AIRI-x.x.x-windows-x64-setup.exe`（约 470 MB）。

### 2.2 如果安装器报错

部分 Windows 环境会遇到：

```
NSIS Error
Error writing temporary file. Make sure your temp folder is valid.
```

这是安装器解压临时文件失败。**绕开办法**：直接解包

```powershell
# 1. 提取内层压缩包
7z e AIRI-x.x.x-setup.exe -o<临时目录> '$PLUGINSDIR\app-64.7z' -y

# 2. 解压到目标目录
7z x <临时目录>\app-64.7z -oD:\AIRI -y
```

解完直接双击 `D:\AIRI\airi.exe` 即可，无需安装。

### 2.3 放哪里

**必须是普通目录**，例如 `D:\AIRI`。

❌ 不要放在：
- 沙箱/受限目录（会导致 Electron 静默启动失败）
- 路径含中文或空格的位置

### 2.4 首次启动

双击 `airi.exe`，首次加载稍慢（10–20 秒）。

可能会遇到：

| 现象 | 处理 |
|---|---|
| SmartScreen 拦截 | 更多信息 → 仍要运行 |
| 弹出登录页 | **不用登录**，找「配置您自己的 AI 服务来源」 |
| 白屏 | 等 30 秒，资源加载慢 |

## 三、接入模型

### 3.1 直连（不用中转站）

设置 → 服务来源 → 聊天 → 选 `DeepSeek`：

```
API Key: sk-xxxx
Base URL: https://api.deepseek.com/v1
模型: deepseek-chat
```

### 3.2 走中转站（推荐）

设置 → 服务来源 → 聊天 → `OpenAI 兼容`：

```
Base URL: http://127.0.0.1:8787/v1
API Key:  local
模型:     deepseek-chat
```

这样才能用人格 + 记忆。

### 3.3 验证

问她「你是谁」：

- 答「大肥鱼」→ 中转站人格注入成功
- 答「我是 AI 助手」→ 还在直连

## 四、导入 Live2D 模型

### 4.1 格式要求

AIRI **只接受 zip 导入**，不是选 `model3.json`。

zip 内的结构：

```
模型.zip
├── xxx.model3.json
├── xxx.moc3
├── xxx.physics3.json
├── xxx.2048/
│   ├── texture_00.png
│   └── texture_01.png
├── motions/
│   └── idle.motion3.json
└── *.exp3.json
```

### 4.2 常见坑：表情不生效

如果你的 `model3.json` 里没有声明表情与动作：

```json
{
  "FileReferences": {
    "Moc": "xxx.moc3",
    "Textures": ["xxx.2048/texture_00.png"],
    "Physics": "xxx.physics3.json"
  }
}
```

导入后角色只会"呼吸"，不会做表情。

**修复**：手动补声明

```json
{
  "FileReferences": {
    "Moc": "xxx.moc3",
    "Textures": ["xxx.2048/texture_00.png"],
    "Physics": "xxx.physics3.json",
    "DisplayInfo": "xxx.cdi3.json",
    "Expressions": [
      { "Name": "happy", "File": "开心.exp3.json" },
      { "Name": "sad", "File": "悲伤.exp3.json" }
    ],
    "Motions": {
      "Idle": [{ "File": "motions/idle.motion3.json" }],
      "TapBody": [{ "File": "motions/wave.motion3.json" }]
    }
  },
  "Groups": [
    { "Target": "Parameter", "Name": "EyeBlink", "Ids": ["ParamEyeLOpen", "ParamEyeROpen"] },
    { "Target": "Parameter", "Name": "LipSync", "Ids": ["ParamMouthOpenY"] }
  ]
}
```

### 4.3 表情名要用英文

AIRI 的情绪键通常是英文（`happy` / `sad` / `angry`）。
中文表情名（`开心` / `悲伤`）可能识别不到，建议同时提供英文别名：

```json
"Expressions": [
  { "Name": "开心", "File": "开心.exp3.json" },
  { "Name": "happy", "File": "开心.exp3.json" }
]
```

### 4.4 导入步骤

设置 → 模型 → 导入 → 选 **Live2D** → 选 zip

导入成功后会显示表情列表。**勾选要启用的表情**，否则聊天不会自动切换。

### 4.5 导入后检查

| 现象 | 结论 |
|---|---|
| 眼睛跟随鼠标 | ✅ 模型与参数正常 |
| 表情列表非空 | ✅ 解析成功 |
| 聊天时表情不变 | 需要手动勾选/映射情绪 |
| 完全不动 | 模型文件不全或版本不兼容 |

## 五、语音（可选）

AIRI 支持语音输入输出，但需要额外服务：

| 能力 | 需要 |
|---|---|
| TTS（她说话） | 语音合成服务，如 Edge TTS / 硅基流动 |
| ASR（你说话） | 语音识别服务 |

不配也能纯文字聊天。

## 六、恢复手册

### 6.1 备份什么

| 内容 | 位置 |
|---|---|
| 程序 | `D:\AIRI\` 整个目录 |
| 数据 | `%APPDATA%\ai.moeru.airi\` |
| 模型 | 你导入的 zip |

### 6.2 换机器怎么恢复

1. 复制 `D:\AIRI` 到新机器同路径
2. 复制 `%APPDATA%\ai.moeru.airi`
3. 双击 `airi.exe`
4. 检查服务来源配置是否还在（不在就重填）

## 八、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 双击没反应 | 目录权限受限 | 移到 `D:\` 普通目录 |
| 安装器 NSIS 报错 | 临时目录写入失败 | 用 7-Zip 解包 |
| 表情列表空 | model3.json 没声明 | 补 `Expressions` 字段 |
| 聊天机器人味重 | 没接中转站 | Base URL 改成 8787 |
| 卡在登录页 | 走了官方账号流程 | 找「配置您自己的服务来源」 |
