# 配置迁移（v1.2）

把中转站搬到另一台电脑，或重装系统前。

## 需要带走什么

| 文件 | 作用 | 不带会怎样 |
|---|---|---|
| `config.json` | 端口、密钥、写回范围等 | 要重新填一遍 |
| `archive.key` | 归档解密密钥（DPAPI 保护） | 旧归档永远解不开 |
| `archive.db` | 原文归档 | 历史原话丢失（记忆库不受影响） |

`config.json` 和 `archive.key` 在 `%APPDATA%\dafeiyu-hub\`。

## 导出

```powershell
cd <安装目录>\resources\sidecar
python migrate_bundle.py export D:\backup\dafeiyu-bundle.zip --with-archive
```

不加 `--with-archive` 只导出配置和密钥，包很小。

⚠️ 包里是明文 API Key 和归档密钥，**不要上传网盘公开链接**。

## 导入

```powershell
python migrate_bundle.py import D:\backup\dafeiyu-bundle.zip
```

导入前会把现有文件备份为 `.bak_<时间戳>`。

## 注意

- `archive.key` 由 Windows DPAPI 绑定当前账户加密；换账户后**旧密钥文件无法直接解密**，
  必须用导出的 bundle 覆盖，并在新机器上重新加密（DPAPI 会重新绑定新账户）
- 导入后重启应用；如果记忆库路径变了，去「配置」页确认
- 只迁记忆库（LivingMemory）不在本工具范围，它有自己的数据目录
