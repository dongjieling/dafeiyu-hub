# ADR-002 多端兼容层

> 状态：已实施（v1.4.0）
> 日期：2026-11-28

## 背景

中转站最早只服务 AIRI + AstrBot 两端，后来需要支持：

- 其他桌面宠物
- 其他聊天托管软件
- MCP 客户端

这些客户端需要不同的 **scope**（会话隔离）、可能不同的人格、以及可选的鉴权。
之前的实现只有一个全局 `write_scope` 和一份人格，接第二个客户端会串台。

## 决策

### 1. 客户端 profile 独立存储

`%APPDATA%\dafeiyu-hub\clients.json`：

```json
{
  "auth_mode": "off",
  "clients": [
    {
      "id": "airi",
      "name": "AIRI",
      "token": "",
      "scope": "airi:desktop",
      "persona_id": "",
      "model": "",
      "enabled": true
    }
  ]
}
```

- `id`：小写字母/数字/下划线，唯一
- `token`：可选；为空表示不校验
- `scope`：为空则用全局 `write_scope`
- `persona_id`：为空则用全局人格
- `model`：为空则用请求或上游默认模型

### 2. 三档鉴权

| auth_mode | 行为 |
|---|---|
| `off` | 不校验，带不带 token 都走默认/匹配到的 profile |
| `optional` | 不带凭据 → 默认；带了但无效 → 401 |
| `required` | 必须带有效 token 或 `X-Hub-Client`，否则 401 |

凭据来源：`Authorization: Bearer <token>` 或 `X-Hub-Client: <id>`。

### 3. 请求级生效配置

每个聊天请求按客户端生成 effective cfg：

- `write_scope` / `scope` → 客户端 scope
- `persona_id` → 客户端人格
- `client_id` → 写入归档会话（`client:<id>`）

人格、记忆召回、写回、归档都用这份 cfg，不改全局配置。

### 4. MCP 也遵守客户端

`mcp_server.py` 读取环境变量 `HUB_CLIENT`：

- 有对应 profile → 用它的 scope/人格
- 没有 → 用全局

注册 AstrBot MCP 时自动创建 `astrbot` profile 并写入 `HUB_CLIENT=astrbot`。

## 后果

### 好处

- 多客户端不串台
- 接入新客户端只需加 profile，不改代码
- 鉴权可选，默认不破坏现有客户端
- MCP 与 HTTP 走同一套隔离

### 代价 / 风险

- `clients.json` 里 token 是明文（本地文件，与 config.json 一致）
- 客户端要支持自定义 `Authorization` 才能用 token；不支持时只能靠 `X-Hub-Client` 或默认 profile
- 人格差异只做了 persona_id 切换，没有做「同一人格不同语气」
- 归档会话按 `client:<id>` 分，旧数据仍在 `desktop`

## 未做

- 远程 MCP（SSE）+ 鉴权
- 每个客户端独立模型参数（温度、召回条数）
- 客户端级用量统计

## 安全补强（v1.5.1）

### 鉴权

- `required` / `optional` 模式只认 `Authorization: Bearer <token>`
- `X-Hub-Client: <id>` 只在 `auth_mode=off` 时用于选择 profile，不能替代 token
- `clients.json` 原子写（临时文件 + `os.replace`）
- 解析失败先回退最近备份；仍失败则 fail-closed 到 `required`，不会静默变 `off`
- 备份保留 5 份

### 管理接口

- 启动生成 `%APPDATA%\dafeiyu-hub\admin.token`（48 位十六进制）
- 除 `/health` 与 `/v1/chat/completions` 外，所有接口要求 `X-Hub-Admin`
- 桌面端自动读取并携带；外部脚本需自己带
- `/v1/clients` 返回掩码 token（`••••` + 末 4 位）
- UI 保存时掩码 token 自动用原值回填

### 隔离

- `extractions` 增加 `client_id` / `scope` / `persona_id`
- outbox 写入使用每行的 scope/persona，不再被全局覆盖
- 去重只比较同一 client（旧数据 null 视作 default）
- MCP `memory_list` 和 `memory://recent` 按 profile scope 过滤
- `airi:desktop` 这类本地 scope 允许写回
- `allow_write` 只控制 MCP 写入，聊天写入不受影响
- 删除记忆/清理索引时同步删除 `graph_edges` 孤儿
